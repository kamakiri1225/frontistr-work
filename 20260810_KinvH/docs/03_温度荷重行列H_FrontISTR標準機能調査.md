# FrontISTRで温度荷重行列Hを出力できるか

## 調査の目的

温度荷重行列 H を、全体剛性行列 K と同じようにFrontISTRの入力キーワードだけで出力できるか調べる。

ここで扱う H は、節点温度ベクトル T を節点熱荷重ベクトル f_thermal に変換する行列である。

```text
f_thermal = H T
```

## 結論

現在使用しているFrontISTR（ソースのコミット `7f48eae0`）には、Hを直接出力する入力キーワードはない。

`!SOLVER` の `DUMPTYPE` で出力できるものは次の2つである。

- `dump_matrix_*.mm`、`.csr`、`.bsr`: 連立方程式の係数行列。静解析では全体剛性行列 K
- `dump_matrix_*.rhs`: その解析で使用する右辺ベクトル

温度を与えた解析では、`.rhs` に温度荷重も含まれる。ただし、出力されるのはHではなく、指定した温度分布に対する1本のベクトル `H T` である。

## 標準の行列出力設定

全体剛性行列と右辺ベクトルは、次の設定で出力できる。

```text
!SOLVER,METHOD=DIRECT,DUMPTYPE=MM,DUMPEXIT=YES
 10000, 1
 1.0e-8, 1.0, 0.0
```

各設定の意味は次のとおり。

- `DUMPTYPE=MM`: Matrix Market形式で係数行列を出力する
- `DUMPTYPE=CSR`: CSR形式で係数行列を出力する
- `DUMPTYPE=BSR`: BSR形式で係数行列を出力する
- `DUMPEXIT=YES`: 行列と右辺を出力した後、方程式を解かずに終了する
- `DUMPEXIT=NO`: 出力後も解析を続ける

`DUMPTYPE` にHを選ぶ値は定義されていない。入力処理が受け付ける値は `NONE`、`MM`、`CSR`、`BSR` だけである。

## Hが出力されない理由

FrontISTRは、静的熱応力解析の内部でHを全体行列として作成していない。

処理の流れは次のとおり。

1. 要素の節点温度から積分点の温度を計算する
2. 熱膨張ひずみを計算する
3. 要素の等価熱荷重ベクトルを計算する
4. 要素ベクトルを全体右辺 `hecMAT%B` に加える

```text
節点温度 T
  -> 要素ごとの温度荷重ベクトル
  -> 全体右辺 f_thermal
```

この処理では、中間に全体行列Hを保持しない。そのため、既存の行列ダンプ処理へHを渡すだけでは出力できない。

ソース上の根拠は次のとおり。

- `fistr1/src/common/fstr_ctrl_common.f90`
  - `!SOLVER` の `DUMPTYPE` は `NONE`、`MM`、`CSR`、`BSR` のみを受け付ける
- `hecmw1/src/solver/matrix/hecmw_matrix_dump.f90`
  - 係数行列を出力した後、`hecMAT%B` を `.rhs` に出力する
- `fistr1/src/analysis/static/fstr_ass_load.f90`
  - 温度荷重を要素ごとに計算し、`hecMAT%B` に加算する
- `fistr1/src/lib/static_LIB_3d.f90`
  - `TLOAD_C3` が3次元ソリッド要素の温度荷重ベクトルを計算する

## Hを直接出力するために必要な改造

1回のFrontISTR実行でH全体を出力するには、ソースコードの変更と再コンパイルが必要になる。

入力は、Kの出力設定と並べて読めるように次の形を候補とする。

```text
!SOLVER,METHOD=DIRECT,DUMPTYPE=MM,DUMPH=YES,DUMPEXIT=YES
```

実装内容は次のとおり。

- `DUMPH=YES/NO` を `!SOLVER` の入力パラメータへ追加する
- 要素温度荷重を計算する箇所で、各節点温度に対する係数を要素Hとして求める
- 要素Hを全体Hへ組み立てる
- `H_matrix.mtx` としてMatrix Market形式で出力する
- 既定値を `DUMPH=NO` とし、通常のFrontISTR解析へ影響を与えない

今回のモデルは四面体一次要素（要素タイプ341）なので、まず341を対象に実装・検証する。その後、必要に応じて他の3次元要素へ広げる。

## 実装時の注意

Hを定数行列として扱うには、材料特性が温度に対して線形であることが前提になる。

- ヤング率やポアソン比が温度で変化しない
- 線膨張係数が温度で変化しない
- 微小変形の線形静解析である
- 基準温度の定義が解析とHの導出で一致している

材料定数が温度依存の場合、`f_thermal = H T` のHは一定にならない。その場合は、基準温度まわりのヤコビアンとしてHを定義するなど、別の扱いが必要になる。

## 次に行う作業

- `DUMPH` を追加するソース変更箇所を確定した
- 要素タイプ341のH組み立て処理を実装した
- 検証用ソースコピーでFrontISTRを再コンパイルした
- `H T` と標準FrontISTRの温度荷重RHSが一致することを確認した
